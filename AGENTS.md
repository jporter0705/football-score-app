# Standing user instructions

- For all work on this project, obtain explicit user approval before creating commits, pushing changes, merging, publishing, or triggering Netlify deployments. Deployments use the user's Netlify credits. A future plan upgrade does not remove this requirement.
- Local inspection, edits, and checks may proceed within the requested scope. Do not interpret permission to edit as permission to commit or deploy.
- Preserve the user's locally replaced icon-192.png and icon-512.png when synchronizing with GitHub. They are pending artwork for a future approved release.
